Oura Personal Archive

A private, single-user tool for keeping a personal copy of my own Oura Ring data.

What this is. A small set of scripts that I run on my own computer. They connect to the Oura API with my own account, download my own measurements, and store them as CSV files on my own disk. That is the entire purpose.

Why it exists

I keep a long-term record of my own health measurements: blood work, body composition, cardiovascular tests. The Oura Ring produces daily sleep, activity and recovery data that belongs in the same record. This tool puts it there.

Who uses it

One person: me. It is not a product, it is not distributed, there is no sign-up, and there are no other users. It has no public interface.

How it works

  • Runs locally on a single personal computer. There is no server and no hosted component.
  • Authenticates through Oura's OAuth 2.0 flow, with the redirect going to localhost on the same machine.
  • Tokens are written to a local file that never leaves the machine.
  • Downloaded data is written to local CSV files.

What it does not do

  • No data is uploaded anywhere, shared with anyone, sold, or used for advertising.
  • No third party receives the data.
  • No accounts, no analytics, no cookies, no tracking.
